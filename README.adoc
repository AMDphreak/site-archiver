= Site Downloader

Comprehensive toolset for downloading and archiving websites to static, offline copies.

== About The Project

A comprehensive toolset for archiving websites to a static, offline format.

link:#readme-top[back to top]

== Components

* **site-downloader-lib**: D-lang library for crawling and link rewriting.
* **site-downloader-cli**: Command-line interface.
* **site-downloader-gui**: Webview-based GUI with page preview and session management.
* **site-downloader-extension**: Chrome extension (WASM-ready) for capturing sessions and triggering downloads.

== Installation

You can download the latest version of Site Downloader from the link:https://github.com/AMDphreak/site-downloader/releases[GitHub Releases] page.

* **Installer**: `site-downloader-setup.exe` (Recommended for Windows)
* **Standalone**: `site-downloader-cli.exe` and `site-downloader-gui.exe`
* **WinGet**: `winget install AMDphreak.SiteDownloader` (After initial submission)

To build from source, ensure you have the link:https://dlang.org/download.html[D compiler and Dub] installed.

link:#readme-top[back to top]

== Usage

=== Quick start

[source,powershell]
----
cd apps/cli
dub run -- --url https://example.com
----

=== CLI

[source,powershell]
----
cd apps/cli
dub run -- --url https://example.com --depth 2
----

To archive only one page and its assets (no following internal links), use `--single-page`:

[source,powershell]
----
cd apps/cli
dub run -- --url https://example.com/ --single-page --output ./single-page-mirror
----

=== GUI

[source,powershell]
----
cd apps/gui
dub run
----

=== Browser Extension

Load `apps/extension` as an unpacked extension in Chrome/Edge to trigger downloads directly from your browser.

TIP: For comprehensive usage instructions, see the link:docs/modules/ROOT/pages/index.adoc#_cli_arguments[CLI Arguments] documentation.

=== Development & Building from Source

==== Prerequisites

* D Compiler (DMD or LDC)
* Dub
* Node.js & pnpm
* corepack enabled

==== Setup

[source,powershell]
----
corepack enable
pnpm install
----

The project uses a monorepo structure:

* `libs/archiver`: Core crawling and link rewriting logic.
* `apps/cli`: CLI frontend.
* `apps/gui`: GUI frontend using `webview-d`.
* `apps/extension`: Chrome/Edge extension.
* `docs`: Antora-based documentation.
